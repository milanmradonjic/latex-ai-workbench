# Version 4.0.0 verification

This records the release that removes the research, notes and Markdown modules (the first step of [the minimal scope](minimal-scope.md)),
tested on 2026-10-13 on macOS (Darwin 25.5, Python 3.14.8, GNU Make 4.4.1 from Homebrew with `gnubin` first on `PATH`, TeX Live with
latexmk 4.88 and Biber 2.21). No hosted run of this repository exists yet: the workflows of this version have not run on GitHub.

## Found on the way

- **Biber failed in the portability run, in the 3.7.0 tree as well.** Its self-extracting cache in the temp folder (`par-<user>`, from 8 October)
  had been partly cleaned by macOS (`Unicode::UCD: failed to find unicore/version`), so it died after "Found BibTeX data source". Removing that
  folder (it is regenerated by the next run) fixed it. This is an environment fault, not a defect of the workbench, and not caused by this change.
- **A deleted file that was not about research.** `docs/tasks.md` ("I want to…") was removed with the research documents by mistake, noticed
  from the README link, and restored and edited.

## Not verified

- **Hosted runs.** The workflows of this version, including the Python workflow that now tests two versions on a pull request, have not run.
- **Python 3.10 to 3.13**, **GNU Make 3.81 as `make`**, **Windows.**
- **A real project.** The owner's own two-document project was not upgraded to 4.0.0.
