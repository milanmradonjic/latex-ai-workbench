# Model {#model}

For the synthetic example, define $x(t) = \exp(-\gamma t)$ with $\gamma > 0$.

$$
\frac{dx}{dt} = -\gamma x, \qquad x(0) = 1.
$$

The expression gives $x(0)=1$ and approaches zero as $t\to\infty$.
These statements illustrate mathematical note rendering, not a validated
physical model. Return to the [notebook](index.md#notebook).
